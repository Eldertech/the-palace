Message Passing
on the Palace

A graph neural network run on the palace's own typed links — 310 entries, 2,402 edges, nothing trained. Every weight is a number chosen by hand, so each run is an argument about how a relation behaves rather than a fit to a loss.

01

One loop, repeated

A GNN is a single rule applied over and over: every node updates itself from its neighbours, then everyone does it again. A Weave is one layer of exactly this.

Hl+1 = s · Hl + K · Σr ar · Dr−1 Ar Hl
(entries, next round) = (self-weight) × (entries, now) + (gain) × Σ over link types (coupling of that type) × (average over that type's neighbours)

A full relational GNN gives every link type its own learned matrix. Here each type gets a single number instead — ten couplings, readable at a glance — which is what lets contradicts be negative. That is the whole experiment.

04

Where the analogy breaks

Two gaps worth keeping open rather than closing.

The palace has a node that can refuse a message. Message passing is synchronous and uniform — every node updates every round, same function, no gate. Ceremonies fire on trigger words, entries sit dormant for months, and TRICKSTER can decline. No GNN has that node.

A GNN learns; the palace is authored. These couplings were fit by nothing. There is no loss function here — the training signal is whether an entry got better, which is a felt question, not a differentiable one.

05

What the controls took back

The first run of this page reported a worse number and a wrong reason. Three follow-up controls moved it. They are here because the corrections are the most useful thing the experiment produced.

The hand-chosen couplings were the problem, not the types. An untyped model — every edge identical, one channel — beat the typed one by a wide margin, which looked like a verdict on the link ontology. It was not. Splitting the gap three ways: over half of it is R-GCN’s per-relation normalisation, which quietly lets one mirrors neighbour outweigh twenty connects-to neighbours; most of the rest is that my ten numbers are simply worse than setting them all to one. Typing itself is worth roughly nothing here either way.

Contradiction is topically close, not far. The repulsive coupling survives as the thing that prevents collapse — setting contradicts to zero collapses the graph just as completely as setting it to +1, so removing attraction is not enough; the negative sign is doing the work. But measuring the raw text distance across each link type, before any message passing, contradicted entries turn out to be the second most similar pair type in the palace, well above a random pair. Of course they are: you have to be arguing about the same thing to contradict at all.

So the negative sign is right for one job and wrong for the other. It maintains distinction, and it wrecks retrieval — because it shoves apart entries that genuinely belong in the same neighbourhood. One scalar cannot say “close, but keep them distinct.” That sentence needs a rotation, not a distance, and a rotation is exactly what the full relational model’s learned matrix can express and this page’s readable simplification cannot.

The types that actually bridge textual distance are the taxonomic ones. exemplifies links entries no more similar than two entries picked at random — an instance and the class it instances share almost no vocabulary — with member-of just behind it. If cross-domain reach is the prize, those are the links doing it.
