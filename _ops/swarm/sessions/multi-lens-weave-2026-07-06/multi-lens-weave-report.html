▸ coordinator · single commit on main
The safety rule that makes parallel writing safe: partition every write by its owning file. No two agents share a file; agents never commit; the coordinator makes the one commit with explicit pathspecs. Anything that touches a shared hub file (SCHEMA, a busy entry) I serialize myself. Destructive moves (merge, compost) go through the composting protocol — marked, not deleted, so a cycle of reversibility stands before anything is lost.
