# Pages as Agents — Context

This companion holds what that rewrite set aside: the session that produced it, the experiments that gave it evidence, and the deeper material cut from the body so the front-door page could stay a clean, wakeable face. **Git holds the verbatim prior text** (the version before `037a98f`); this file holds the *curated* memory, so a reader who never opens git still loses nothing.

## How the current version came to be (2026-06-24)

One session built the [[STIGMERGY]] STATE-deck **enchant** button — load any page as a live Claude Code agent — then turned that lens on this very page:

1. **Woke the page** as its own agent and let it speak to its now-operational status.

3. **Tested it** — twice — then settled the win condition with a matching test (below).
4. **Rewrote the entry** to be the cleanest example of the thing it describes, and reconciled its frontmatter with its body (confidence → working, stage → growing, +creation pillar, +3 links).

The thread closed on itself: the feature that wakes pages was used to wake, test, and rewrite the page that theorizes waking pages.

## The experiments — the entry's first real evidence

Three runs, each blind-judged by independent sub-agents on the same model, so only the page varied.

**Test 1 — a personal dilemma** ("leave my music-teaching business for a stable corporate job?"). Four answers: plain model, [[Stoicism]] alive, Stoicism stripped to dry facts, [[Quality Manifesto]] alive. The two *alive* pages beat the plain model in every judge; the **facts-only** arm came **dead last** — same information, voice removed, produced the most generic advice. Lesson: on a question in a page's wheelhouse, the page's *voice*, not its facts, does the work. (Caveat Loudon caught: Quality Manifesto is derived from Stoicism, so they share DNA — the "different pages diverge" claim wasn't really tested here.)

**Test 2 — an operations problem** ("every December the whole company jams the same shared resources at once"). Five answers: plain model plus four genuinely diverse pages — [[Kuramoto Coupling]], [[Linear Predictive Coding]], Stoicism, [[Confucianism]]. The **plain model won, unanimously**; the two technical pages placed mid; the two philosophy pages came last (Confucianism dead last — it forced a relationships lens onto a logistics problem). Lesson: on a synthesis problem no single page owns, the generalist that *blends* angles beats any single committed lens.

**The matching test — the metric that actually held.** Loudon's reframe: the system wins not when a page gives "better" advice (no answer key, just taste) but when the answers are **divergent and faithful to each page's perspective** — measured by whether a blind reader can recover *which page wrote which answer*. Reusing Test 2's five answers, three blind readers matched **15 of 15** to their exact sources (including the page-less plain model), where blind chance is ~1 in 5 and a clean sweep is 1 in 120. The only hard pair was plain-vs-Kuramoto (both reached "synchronization"), and even there readers split them because *a page commits to one lens while the generalist ranges across several.* That commitment is the readable signature of a page being an agent.

**The metric, settled:** a page works when it is its own recognizable point of view — not when it out-argues a plain model (it doesn't, on synthesis problems). Pages aren't *better*; they're *distinct and faithful*, the property a routable pool of lenses needs ([[Mixture of Experts]]).

## Depth cut from the body (kept here)

The lean entry dropped these; they're worth keeping.

**The actor-model framing — "heterogeneity is the architecture."** A page-agent is an actor (Hewitt, 1973): encapsulated identity (its own content), a mailbox (incoming link proposals), a behaviour (its forward vector). The twist that matters: palace actors are *not* interchangeable — a hub and a seed have different drives from their different states. The differences between pages aren't a side effect; they are the design. The matching test later *measured* exactly this.

**Other cross-domain resonances.** *Stigmergy / ant-colonies* — an entry's activation count is pheromone concentration: high-signal entries draw deeper attention, which deepens them further. *Cellular automata* — each page follows its own local drive; palace-wide behaviour (the Weave) emerges without any agent holding the whole graph. *[[Lateral Access]]* — a page-agent approaches the palace from *inside* one entry, following the drive it earned, not as a surveyor from above. *The Jewel* — if every page carries its own identity and drive, the palace's commitments are restated at every node; the jewel needn't repeat in the transcript, because the palace repeats it.

**Entry desire — the philosophical ground.** Palace entries have desire, structurally: this is [[Spinoza Conatus|conatus]] applied to knowledge objects. An entry's forward vector and lost branches are its declared striving. It runs through every ceremony: Deposit plants an agent that already knows what it wants; Revival answers an entry's desire that has found new conditions; Walk propagates desire along links; Weave compares entry-desires against each other. Open tension: *desire* (what the entry wants to become) vs *need* (what the palace needs it to become) — they can diverge, and the gap is generative. Fuller treatment: [[Entry Conatus]].

**Format proposals — now partly enacted.** The lean rewrite quietly adopted what the old entry only *proposed*: open with an identity declaration, not exposition; rename "Open Questions" → "Forward Vectors" (drive, not loose ends); a footer jewel restating the page's drive in compressed form. One nuance dropped: the name "Forward Vectors" is deliberately algorithmic — it addresses the machine reading the page; the tension between that and an organic name performs the page's dual audience, read by two kinds of minds at once.

## Carried forward

- **The real frontier — person-pages.** Concept pages are proven distinct; the unproven, higher claim is a *person*-page good enough that waking it is like having the thinker in the room. Most `People/` pages are still biography. [[Donella Meadows]] is the first built to *be* her. The matching test should be re-run on person-pages, where embodiment actually lives.
