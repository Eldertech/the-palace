**What it said** (verbatim):

> They face different readers.
>
> **The scroll is a face.** It's for someone meeting the page. It opens with where the page stands now, then lists everything the page has made or done, newest first. For a project that means its proofs and media. For a ceremony it means its runs. It answers "what has this page done?"
>
> **The ledger is memory.** It's for the next worker who has to run the thing again. Only ceremonies keep one. It holds what running the ceremony taught, and every run leaves a line. It answers "what did we learn from doing it?"
>
> A ceremony has both, and that's where the difference is clearest. The scroll records that a run happened and what it produced. The ledger records the lesson from that run, like a step that kept getting skipped or a prompt that needed rewording. You could read a whole scroll and still not know how to run the ceremony better. The ledger is there so you do.
>
> A project page gets a scroll but no ledger. Its lessons belong in its Context, the other part of memory, which holds what the page left out and why it's shaped the way it is.
>
> This comes from the "A page and its folder" section of `CLAUDE.md`. I haven't opened an actual scroll or ledger, so if the real files have drifted from that description, I wouldn't know.
