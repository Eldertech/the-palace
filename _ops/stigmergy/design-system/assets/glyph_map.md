# Glyph map -- the STIGMERGY "icon set"

Icons are typed, not drawn. Use these characters directly in markup.

## State / status
| Meaning | Glyph |
|---|---|
| Unread | `*` |
| New / fresh | `!` |
| Locked | `#` |
| Pinned | `▲` |
| Running | `|` `/` `-` `\` (animate) |
| Connected | `●` |
| Disconnected | `○` |
| Error | `✕` or `X` |
| Ok | `✓` or `OK` |

## Navigation
| Meaning | Glyph |
|---|---|
| Prompt | `>` |
| Reply depth | `>` `>>` `>>>` |
| Back | `<─` |
| Forward | `─>` |
| Expand | `[+]` |
| Collapse | `[-]` |

## Box drawing (single)
```
┌ ─ ┐
│   │
└ ─ ┘
```

## Box drawing (double)
```
╔ ═ ╗
║   ║
╚ ═ ╝
```

## Mixed + T-pieces
```
├ ┤ ┬ ┴ ┼
╠ ╣ ╦ ╩ ╬
```

## Shading / fill
```
░ ▒ ▓ █
```

## Bullets + separators
```
·   •   ·.·.·   ───   ═══   ┈┈┈
```
