# Baton: STIGMERGY v2.0 — Weave proposals (posting half)

## Move

## Why this move matters
The whole Weave-proposals loop now works end-to-end (detect → propose → grant & apply → committed typed link), but the *propose* step is a hand-run CLI. The v2.0 thesis is "the single surface Loudon operates," so the audit should run from the terminal, not a shell. This is the bounded, sibling-shaped next step — not a new direction. The larger directions (generative proposal types, the autonomous scheduler) are the roadmap's Still-open and deliberately NOT this move.
