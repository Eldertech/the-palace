# Sandbox — Nodes Primary

What is fundamental is the node, not the relation. A thing exists with its own properties before
any edge is drawn to it; relations are merely the ways we notice or use things that were already
there. Delete every edge and the nodes remain; delete every node and there is nothing left to
relate.

This **contradicts [[Sandbox — Relations Primary]]**, and the contradiction is deliberate: both
are true from where they stand, and the friction between them is the point. Read them as a pair.
