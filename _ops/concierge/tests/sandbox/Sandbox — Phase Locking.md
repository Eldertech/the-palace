# Sandbox — Phase Locking

Phase locking is the steady state two or more oscillators reach when their phase difference
stops changing — they may run at an offset, but the offset holds. It is the microscopic event
underneath macroscopic synchronization: a system is synchronized precisely when its parts have
phase-locked.

The phenomenon spans domains. Fireflies flashing in unison, pacemaker cells in the heart, the
moon's rotation locked to its orbit, metronomes on a shared board, an audience's applause
tipping into rhythm — each is phase locking wearing different material. It couples-with
**[[Sandbox — Coupling Constant]]** (the lock only holds above a threshold of mutual influence)
and gives rise to **[[Sandbox — Emergence Field]]** (locked parts produce a field no single part
carries). The lock can be partial, intermittent, or chimeric — some parts locked while others
drift — which is where the richest behavior lives.

Three regimes are worth distinguishing: full locking (all parts, one offset), cluster locking
(sub-populations lock separately), and the chimera state (coexisting locked and drifting
regions in an identical population). Each has its own onset condition and its own signature in
the order parameter. A mature treatment would work each regime with its governing inequality.
