The math (per agent, each step)

sense three points ahead:
 F = trail( pos + reach·dir0 )
 L = trail( pos + reach·dir+α )
 R = trail( pos + reach·dir−α )
rotate toward the strongest:
 if F ≥ L,R → keep heading
 else if L > R → θ += turn
 else → θ −= turn
step pos += step·(cosθ, sinθ)
deposit trail(pos) += 1
field each frame: blur(diffusion) · (1−decay)

α sensor_angle, turn turn_speed, reach sensor_distance. Food injects trail every frame; the sink pulls heading. Starve = high decay → only load-bearing tubes survive.
