The Report

What was built

Starting from no infrastructure, a RunPod serverless endpoint was provisioned end-to-end on the account via API: a template pointing at the runpod/worker-comfyui:5.8.4-sdxl worker image, an 80 GB container disk, and a GPU pool of 24 GB–48 GB cards. The endpoint scales to zero when idle and was driven entirely over HTTPS by a small Python client (runpod_specialist.py) — submit job → poll → decode → save.

Technology

Model: Stable Diffusion XL base 1.0 running inside ComfyUI (RunPod's worker-comfyui). Sampling: dpmpp_2m / karras, 32–36 steps, CFG 7.0–7.5. Images returned as base64 in the job output and written to disk. GPUs that served jobs were drawn from the pool — primarily an RTX A4500 (20 GB) in the EU-RO-1 datacenter, with additional workers spun up for parallelism.

Time

Total GPU execution across 38 images: 526 seconds (~8.8 min), averaging 13.8s per image. Generation itself is fast; the real latency was one-time cold starts — the SDXL worker image is ~19 GB compressed, so the first worker on a fresh host spent several minutes pulling and extracting it (observed cold-start delays: median ~44s, max ~180s once warm pulls kicked in). Once a worker was warm, images flowed in ~13s each, and running up to 5 workers in parallel cleared the 15-image batches in roughly a minute of wall-clock each.

Cost

Total spend for the entire session — including all the provisioning trial-and-error — was about $0.32. The 38 delivered images accounted for roughly $0.27, or about $0.007 per image. Serverless billed only for active compute; the endpoint costs nothing while scaled to zero. Storage and egress were negligible (RunPod charges no egress).

The one real snag

The initial FLUX-schnell worker image bundles full-precision weights (~24 GB) that don't fit a 24 GB card, so ComfyUI OOM'd and the worker accepted no jobs. Switching to the lighter SDXL image fixed it. Lesson for the backend doc: match the worker image's VRAM footprint to the GPU pool, and be patient through the first cold pull rather than recycling workers mid-extract.
