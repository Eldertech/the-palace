# The Multilinear Self — projection roster

The living list of the projections Loudon presents as. Each is a true cast of one [[The Multilinear Self|multilinear self]] into a context — honest, partial, never a disguise. One conserved nature (the floor: voice + [[Hyperdimensional Prism|Lissajous sigil]] + the nevers); many projections above it. [[Trickster]] is the one who switches between them; [[Stoicism]] is the counterweight that keeps the growing list healthy rather than performative.

## How growth is hardened

To make adding a projection cheap *forever*, three things are fixed and one thing is kept tiny. This is [floor-and-field](The Multilinear Self.md) applied to the roster itself.

**1 · The record (fixed shape).** Every projection fills the same stub — never invent structure, only fill blanks:

```
### <name>
- room:     <the context it serves — REQUIRED; no room = decoration, not a projection>
- tone:     <2–3 words>
- skin:     <one of the six house skins · or "own">
- wordmark: <how the name is set — type treatment / any naming rule>
- gloss:    <one honest line>
- status:   seed · active · dormant · retired
```

**2 · The ritual (fixed act).** Trigger: *"new projection [name]."* It always does the same three moves — draft the record from context → run the gate → append the row. Low ceremony, like a line in Palace Graffiti.

**3 · The gate (fixed, tiny — never grows).** Two questions, unchanged as the roster scales: *does it conserve the nature (voice · sigil · the nevers)?* and *does it name a room?* Because the gate never grows, the 50th projection costs what the 2nd did. That flat cost is the whole point.

**4 · The promotion path.** A projection is born as a row (cheap). When one accrues its own artifacts, voice, and history, it graduates to its own bundle sub-page — the same move as concept→hub at 5 links, or a [[Maker|Shop]] Specialist earning its first job. Rows for the many; pages for the few.

**The Stoic guardrail.** Growth is encouraged, but not infinite. Past some point more projections become performance, not range (see [[The Multilinear Self]] § the Stoic counterweight). Add when a real room asks for a projection — not to fill the list.
